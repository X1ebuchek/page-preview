# @xlebuchek/page-preview

Браузерный веб-компонент `<page-preview>`. Получает URL HTML-страницы, извлекает
`document.title` и первый `<h1>`, а затем показывает компактную карточку-ссылку.

Исходный код: https://github.com/X1ebuchek/page-preview

## Установка

```bash
npm install @xlebuchek/page-preview
```

## Использование

Корневой импорт пакета сразу регистрирует элемент — дополнительных вызовов не нужно:

```js
import '@xlebuchek/page-preview';
```

```html
<page-preview src="/pages/example.html"></page-preview>
```

Атрибут `src` — URL HTML-документа. Относительный URL разрешается относительно
адреса страницы, на которой находится компонент. Страница должна быть доступна
браузерному `fetch` (тот же origin либо корректные заголовки CORS), иначе
компонент перейдёт в состояние `error`.

## Состояния

`data-status` на самом элементе:

- `loading` — запрос выполняется;
- `ready` — данные загружены и отображены;
- `error` — HTTP-ошибка, сетевая ошибка, отсутствующий или некорректный `src`.

## Внутренний интерфейс (Shadow DOM)

- `<a part="link">` — настоящая ссылка, `href` ведёт на разрешённый URL `src`;
- `<span part="title">` — `document.title.trim()`, либо `Название отсутствует`;
- `<span part="heading">` — `textContent.trim()` первого `h1`, либо `Заголовок отсутствует`.

Содержимое полученной страницы выводится только как текст и никогда не вставляется
через `innerHTML`, поэтому разметка из чужих документов не исполняется.

## Локальная проверка

```bash
npx serve .
# либо
python -m http.server 8000
```

Откройте `http://localhost:8000/demo/` (не через `file://`). В `demo/` есть
`example.html` (с заголовком), `empty.html` (без `title` и `h1`) и отсутствующий
`missing.html` (ответ 404).
